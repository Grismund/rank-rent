Use this **pool cost calculator Port St. Lucie** tool to get a quick estimate for your new pool project. Select your pool type, size, and optional features to see a price range based on current Treasure Coast contractor pricing.

## How This Calculator Works

Start by selecting a pool construction type — gunite (concrete), fiberglass, or vinyl liner. Each type has a different base cost range. Then add optional features like a screen enclosure, pool heater, saltwater system, spa, or deck upgrade. The calculator combines the base pool cost with each selected feature to show a total estimated range.

The estimate reflects what Treasure Coast contractors are currently quoting for each component. It does not account for site-specific variables like water table depth, yard access, soil conditions, or HOA requirements. Those factors are assessed during a free on-site evaluation.

## How We Calculate These Ranges

The price ranges come from Treasure Coast pool contractor pricing for each pool type and feature category:

- **Gunite / Concrete base pool:** $35,000 to $65,000
- **Fiberglass base pool:** $25,000 to $55,000
- **Vinyl liner base pool:** $25,000 to $45,000
- **Screen enclosure:** $5,000 to $15,000
- **Pool heater:** $2,000 to $5,000
- **Saltwater chlorine generator:** $1,000 to $3,000
- **Spa / hot tub add-on:** $5,000 to $15,000

The low end of the range reflects a standard-size pool with basic finishes in a straightforward yard. The high end reflects a larger pool with premium finishes, complex site conditions, or design customization. Most homeowners land somewhere in the middle.

For a detailed breakdown of what drives cost, see the [cost guide](/cost/). The [gunite vs. fiberglass vs. vinyl guide](/guides/gunite-vs-fiberglass-vs-vinyl-pools/) explains the construction differences behind the price differences.

## Cost Estimator FAQ

### How accurate is this pool cost calculator?

The calculator provides a ballpark range based on Treasure Coast contractor pricing for the pool type and features you select. Actual quotes will vary based on yard conditions, water table depth, access, and the specific contractor. Use it as a starting point, then request a free on-site estimate for a real number.

### Does the estimate include a screen enclosure?

Only if you select screen enclosure as an add-on feature. The base pool estimate covers the pool shell, plumbing, equipment, and standard concrete deck. Screen enclosures ($5,000 to $15,000), heaters, saltwater systems, and other features are added separately.

### Why is the range so wide?

Pool pricing depends on many variables — pool size, depth, shape complexity, site conditions, water table depth, and material selections. A 10-by-20 fiberglass plunge pool in a flat, accessible yard costs significantly less than a 16-by-40 custom gunite pool with an integrated spa on a lot with high groundwater and limited access.

### Does this include permit fees?

No. St. Lucie County pool permit fees are approximately $461 (including state surcharge). Screen enclosure permits are approximately $180. These are fixed costs added on top of the construction estimate.
